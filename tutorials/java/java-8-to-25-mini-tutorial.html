Wersje między LTS (9,10,12–16,18–20,22–24) — krótki cykl 6 mies.; na prod zwykle skaczesz LTS → LTS.

Java 8 — rewolucja funkcjonalna

Lambda — funkcje jako wartości: (a, b) -> a + b
Stream API — przetwarzanie kolekcji deklaratywnie: filter, map, reduce, collect
Optional — jawna obsługa null zamiast NPE
java.time — LocalDate, ZonedDateTime (koniec Date/Calendar)
Default methods — implementacja w interfejsie bez łamania starych klas
Method references — Author::getName
List<String> names = authors.stream()
    .filter(a -> a.isActive())
    .map(Author::getLastName)
    .sorted()
    .toList();   // toList od J16 — w J8: .collect(Collectors.toList())

9–10

  • JPMS (moduły) — module-info.java, kontrola eksportu pakietów
  • JShell — REPL do eksperymentów
  • Factory methods kolekcji — List.of(), Set.of(), Map.of() (niemutowalne)
  • Java 10: var — inferencja typu zmiennej lokalnej (nie dla pól/metod)
var authors = List.of("Anna", "Jan");   // List<String>
var map = Map.of("id", 1, "name", "X"); // max 10 par w Map.of

Java 11 — drugi LTS

  • HTTP Client — java.net.http (HttpClient, async, HTTP/2) — zamiast HttpURLConnection
  • String: isBlank(), lines(), strip(), repeat(n)
  • Files.readString / writeString
  • Optional.isEmpty() — zamiast !isPresent()
  • Usunięcie modułów Java EE / CORBA z JDK — JAXB, JAX-WS osobno
  • Epsilon GC — no-op GC (benchmarki)
var client = HttpClient.newHttpClient();
var request = HttpRequest.newBuilder(URI.create(url)).GET().build();
var response = client.send(request, HttpResponse.BodyHandlers.ofString());

Java 25 — LTS 2025

Największy skok produkcyjny po 21 — język prostszy na start, runtime szybszy, concurrency dojrzalsze.

Język i składnia (final / preview)

  • Scoped Values (JEP 506, final) — zamiennik ThreadLocal dla virtual threads
  • Module Import Declarations (511) — import module java.base; krótsze importy
  • Compact Source Files + Instance Main Methods (512) — void main() bez public static i klasy wrapper — hello world jednym plikiem
  • Flexible Constructor Bodies (513) — kod przed super()/this() w konstruktorze
  • Primitive patterns (507, preview) — pattern matching na typach prymitywnych w switch
  • Structured Concurrency (505, 5. preview) — StructuredTaskScope
  • Stable Values (502, preview) — immutable lazy init (JEP)

Runtime, GC, wydajność (Project Leyden / HotSpot)

  • Compact Object Headers (519) — mniejszy overhead obiektów na heap
  • Ahead-of-Time Method Profiling (515) — szybszy start, lepsze JIT po restarcie
  • Ahead-of-Time Command-Line Ergonomics (514)
  • Generational Shenandoah (521) — GC niskich opóźnień z generacjami
  • JFR: CPU-Time Profiling, Cooperative Sampling, Method Timing & Tracing

API i inne

  • Key Derivation Function API (510) — crypto KDF w standard library
  • Vector API (508, incubator) — SIMD
  • Usunięcie portu 32-bit x86
// JEP 512 — compact entry (uproszczony start)
void main() {
    IO.println("Hello Java 25");
}

// Scoped Values — kontekst bez kosztu ThreadLocal × miliony wątków
private static final ScopedValue<User> CURRENT_USER = ScopedValue.newInstance();

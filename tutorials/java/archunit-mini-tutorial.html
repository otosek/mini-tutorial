Fundamenty

ArchUnit sprawdza reguły architektury na bytecode — tak jak JUnit sprawdza zachowanie. Łamiesz konwencję pakietów albo warstw → test pada w CI, zanim kod trafi na main.

  Kod źródłowy  →  kompilacja  →  .class
                                        ↓
                              ClassFileImporter (ArchUnit)
                                        ↓
                              JavaClasses + reguły (should)
                                        ↓
                              AssertionError z opisem naruszenia

Reguła ma postać: elementy (noClasses, classes, methods…) + warunek (resideIn…, dependOn…) + asercja (should…, because…).

Zależności i import

Maven / Gradle

</dependency>
// Gradle (Kotlin DSL)

Import klas do analizy

import com.tngtech.archunit.core.domain.JavaClasses;
import com.tngtech.archunit.core.importer.ClassFileImporter;
import com.tngtech.archunit.core.importer.ImportOption;

JavaClasses production = new ClassFileImporter()
    .withImportOption(ImportOption.Predefined.DO_NOT_INCLUDE_TESTS)
    .importPackages("com.acme.shop");

JavaClasses allIncludingTests = new ClassFileImporter()
    .importPackages("com.acme.shop");

Po co DO_NOT_INCLUDE_TESTS: testy często łamią reguły produkcyjne (np. bezpośredni dostęp do repozytorium) — nie chcesz ich liczyć do reguł architektury aplikacji.

Minimalny test JUnit 5

@AnalyzeClasses(packages = "com.acme.shop",
    importOptions = ImportOption.Predefined.DO_NOT_INCLUDE_TESTS)
class ArchitectureTest {

  @ArchTest
  static final ArchRule no_joda_time =
      noClasses().should().dependOnClassesThat()
          .resideInAnyPackage("org.joda.time..");
}

API reguł — klasy, metody, pola

Poniżej gotowe wzorce — kopiuj i dopasuj pakiety do swojego projektu (com.acme..).

Nazewnictwo i modyfikatory

ArchRule services_named = classes()
    .that().resideInAPackage("..service..")
    .and().areTopLevelClasses()
    .should().haveSimpleNameEndingWith("Service")
    .because("spójne nazewnictwo serwisów");

ArchRule dto_immutable = classes()
    .that().haveSimpleNameEndingWith("Dto")
    .should().haveOnlyPrivateConstructors()
    .andShould().haveOnlyFinalFields();

ArchRule no_public_fields = noFields()
    .that().areDeclaredInClassesThat().resideInAPackage("..domain..")
    .should().bePublic();

Adnotacje i dziedziczenie

ArchRule controllers = classes()
    .that().resideInAPackage("..web..")
    .and().haveSimpleNameEndingWith("Controller")
    .should().beAnnotatedWith(RestController.class);

ArchRule repos_are_interfaces = classes()
    .that().haveSimpleNameEndingWith("Repository")
    .should().beInterfaces();

ArchRule entities_extend_base = classes()
    .that().areAnnotatedWith(Entity.class)
    .should().beAssignableTo(AbstractEntity.class);

Zależności między klasami

ArchRule domain_pure = noClasses()
    .that().resideInAPackage("..domain..")
    .should().dependOnClassesThat()
    .resideInAnyPackage("..infrastructure..", "..web..", "org.springframework..");

ArchRule no_entity_in_web = noClasses()
    .that().resideInAPackage("..web..")
    .should().accessClassesThat().areAnnotatedWith(Entity.class);

ArchRule util_no_spring = noClasses()
    .that().resideInAPackage("..util..")
    .should().dependOnClassesThat().resideInAnyPackage("org.springframework..");

Metody i konstruktory

ArchRule no_system_out = noMethods()
    .should().callMethod(System.class, "out");

ArchRule repository_methods = methods()
    .that().areDeclaredInClassesThat().haveSimpleNameEndingWith("Repository")
    .and().arePublic()
    .should().haveNameMatching("find.*|save|delete.*");

ArchRule rest_endpoints_are_mapped = methods()
    .that().areDeclaredInClassesThat().areAnnotatedWith(RestController.class)
    .and().arePublic()
    .and().doNotHaveName("")
    .should().beAnnotatedWith(GetMapping.class)
    .orShould().beAnnotatedWith(PostMapping.class)
    .orShould().beAnnotatedWith(PutMapping.class)
    .orShould().beAnnotatedWith(DeleteMapping.class)
    .orShould().beAnnotatedWith(RequestMapping.class);

Pola i wstrzykiwanie

ArchRule no_field_injection = noFields()
    .that().areDeclaredInClassesThat().resideOutsideOfPackage("..legacy..")
    .should().beAnnotatedWith(Autowired.class);

ArchRule logger_static_final = fields()
    .that().haveRawType(Logger.class)
    .should().bePrivate()
    .andShould().beStatic()
    .andShould().beFinal();

Cykle w pakietach

ArchRule no_cycles = slices()
    .matching("com.acme.(*)..")
    .should().beFreeOfCycles();

Warstwy i zależności pakietów

Najczęstszy scenariusz: kontroler → serwis → repozytorium, bez skrótów w dół.

layeredArchitecture (klasyczne warstwy)

@ArchTest
static final ArchRule layers = layeredArchitecture()
    .consideringAllDependencies()
    .layer("Controllers").definedBy("..web..", "..controller..")
    .layer("Services").definedBy("..service..", "..application..")
    .layer("Persistence").definedBy("..persistence..", "..repository..")
    .layer("Domain").definedBy("..domain..")

    .whereLayer("Controllers").mayNotBeAccessedByAnyLayer()
    .whereLayer("Services").mayOnlyBeAccessedByLayers("Controllers")
    .whereLayer("Persistence").mayOnlyBeAccessedByLayers("Services")
    .whereLayer("Domain").mayOnlyBeAccessedByLayers("Services", "Persistence");

Onion / ports & adapters

ArchRule onion = layeredArchitecture()
    .consideringAllDependencies()
    .layer("Domain").definedBy("..domain..")
    .layer("Application").definedBy("..application..")
    .layer("Adapters").definedBy("..adapter..", "..web..", "..persistence..")

    .whereLayer("Domain").mayOnlyBeAccessedByLayers("Application", "Adapters")
    .whereLayer("Application").mayOnlyBeAccessedByLayers("Adapters")
    .whereLayer("Adapters").mayNotBeAccessedByAnyLayer();

Moduły Maven (opcjonalnie)

ArchRule api_no_impl = noClasses()
    .that().resideInAPackage("..api..")
    .should().dependOnClassesThat()
    .resideInAnyPackage("..internal..", "..impl..");

Agregaty i repozytoria

    .that().haveSimpleNameEndingWith("Repository")
    .should().haveSimpleNameMatching(".*(Order|Customer)Repository");

Slice po feature (moduły pionowe)

    .matching("com.acme.order.(*)..")
    .should().notDependOnEachOther();

ArchRule catalog_independent = noClasses()
    .that().resideInAPackage("com.acme.catalog..")
    .should().dependOnClassesThat().resideInAPackage("com.acme.order..");

Hexagonal — porty w domain, adaptery na zewnątrz

ArchRule ports_in_domain = classes()
    .that().haveSimpleNameEndingWith("Port")
    .or().haveSimpleNameEndingWith("Repository") // port persystencji
    .and().resideInAPackage("..domain..")
    .should().beInterfaces();

ArchRule domain_does_not_know_adapters = noClasses()
    .that().resideInAPackage("..domain..")
    .should().dependOnClassesThat().resideInAnyPackage("..adapter..", "..web..");

ArchRule adapters_may_use_domain = classes()
    .that().resideInAPackage("..adapter..")
    .should().onlyDependOnClassesThat()
    .resideInAnyPackage("..domain..", "..application..", "..adapter..",
        "java..", "javax..", "jakarta..", "org.springframework..", "com.fasterxml..");

Freeze i ArchTests

Freeze zapisuje aktualne naruszenia do pliku — nowe łamania reguły padają, stare dług techniczny możesz migrować stopniowo.

import com.tngtech.archunit.library.freeze.FreezingArchRule;

@ArchTest
static final ArchRule freeze_layer_violations = FreezingArchRule.freeze(
    layeredArchitecture()
        .consideringAllDependencies()
        // ... definicja warstw jak wyżej
);

// Plik: src/test/resources/archunit_store/...

ArchTests — wspólne reguły w wielu modułach

public class SharedArchitectureRules {
  public static ArchRule noStandardStreams() {
    return noClasses().should().accessClassesThat()
        .belongToAnyOf(System.class, Runtime.class);
  }
}

class ModuleAArchitectureTest {
  @ArchTest static final ArchRule streams = SharedArchitectureRules.noStandardStreams();
}

Predykaty i reguły własne

DescribedPredicate

DescribedPredicate<JavaClass> isApiModel = new DescribedPredicate<>("API model class") {
  @Override
  public boolean test(JavaClass input) {
    return input.isAnnotatedWith(Schema.class)
        || input.getSimpleName().endsWith("Request")
        || input.getSimpleName().endsWith("Response");
  }
};

ArchRule openapi_models = classes()
    .that(isApiModel)
    .should().resideInAnyPackage("..api..", "..dto..");

ArchCondition (własna asercja)

ArchCondition<JavaClass> haveSinglePublicConstructor = new ArchCondition<>(
    "have exactly one public constructor") {
  @Override
  public void check(JavaClass item, ConditionEvents events) {
    long count = item.getConstructors().stream()
        .filter(c -> c.getModifiers().contains(PUBLIC)).count();
    if (count != 1) {
      events.add(SimpleConditionEvent.violated(item,
          item.getFullName() + " ma " + count + " publicznych konstruktorów"));
    }
  }
};

ArchRule dto_shape = classes()
    .that().haveSimpleNameEndingWith("Dto")
    .should(haveSinglePublicConstructor);

allowEmptyShould — pułapka

// Gdy żaden element nie pasuje do .that() — domyślnie test PRzechodzi
classes().that().resideInAPackage("..nonexistent..")
    .should().bePublic(); // false sense of security!

// Jawne oczekiwanie pustego zbioru:
classes().that().resideInAPackage("..legacy.v1..")
    .should().beEmpty();

Typowe błędy

  1. Import testów do reguł produkcyjnych — test integracyjny łamie warstwy; używaj DO_NOT_INCLUDE_TESTS.
  2. Zbyt wąski importPackages — reguła nie widzi klas z innego modułu i przechodzi mimo realnego naruszenia.
  3. consideringOnlyDependenciesInLayers() vs consideringAllDependencies() — pierwsze ignoruje zależności „poza warstwami”; wybierz świadomie.
  4. Reguły na Lombok / bytecode — syntetyczne klasy, buildery; czasem trzeba ImportOption.DoNotIncludeGeneratedSources lub wykluczyć ..generated...
  5. Reflection / Spring proxies — zależności przez CGLIB mogą wyglądać inaczej; testuj na „czystym” kodzie lub używaj onlyDependOnClassesThat z wyjątkami.
  6. Freeze bez review — plik store rośnie i nikt nie usuwa starych naruszeń; traktuj freeze jako tymczasowy most.
  7. Zbyt sztywne nazwy — *Service łamie OrderApplicationService vs OrderService; doprecyzuj regex.
  8. Brak because() — przy failu w CI zespół nie wie, po co reguła istnieje.
  9. Duplikacja reguł w każdym module — wyciągnij do ArchTests / biblioteki wewnętrznej.
  10. Uruchamianie tylko lokalnie — bez fazy test w CI reguły architektury nie chronią main.

Podsumowanie: ArchUnit to „kontrakt architektury” w repozytorium — zacznij od 3–5 reguł (warstwy, brak encji w web, brak field injection), potem dokładaj slice i freeze tam, gdzie masz legacy.
